# Abstract: EchoSight - AI-Powered Visual Companion for the Visually Impaired

Navigating and understanding complex environments remains a significant challenge for the visually impaired community. EchoSight is a novel, browser-based artificial intelligence application designed to serve as a real-time visual companion, bridging the gap between visually impaired individuals and their physical surroundings. By leveraging advanced multimodal large language models—specifically Google's Gemini Vision AI—alongside local edge-computing models for face and object detection, EchoSight processes continuous camera feeds to provide comprehensive scene understanding. 

The system operates entirely hands-free, seamlessly integrating natural language voice interactions via the Web Speech API. Users can issue conversational commands to identify objects, read text, count people, and assess environmental conditions like lighting. Crucially, EchoSight prioritizes user safety by automatically identifying hazards such as stairs, vehicles, and temporary obstacles. To enhance spatial awareness, the application employs the Web Audio API to deliver 3D spatial audio cues, allowing users to audibly intuitively perceive the direction and proximity of nearby objects. 

Built on a modern React and TypeScript web stack, EchoSight effectively eliminates the need for expensive, specialized hardware or native app installations. It makes advanced accessibility tools robustly available through any standard smartphone or computer browser. Through a combination of low-latency cloud AI processing and privacy-conscious local fallbacks, EchoSight empowers visually impaired individuals with enhanced autonomy, real-time situational awareness, and confidence in navigating their daily lives.
